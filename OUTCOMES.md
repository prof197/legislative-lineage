## The live track's timing

Once the live track runs during a legislative session ([DESIGN.md](DESIGN.md#updates)), this file will also report, each week, how long the week's new bills took from their introduction to their matches surfacing: their relatives in other states and their documented origins, on their pages and in the feed. Each week's figure will name the command and the committed report it comes from, as every figure in this repository does, and how each end of the interval is dated is set with that command. Nothing is reported before the track has run in session.

That figure is the project's own measurement, not a use of the tool, so it needs no one's permission. An entry in the table above is still added only with the user's permission.
